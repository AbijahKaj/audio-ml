# audio-ml Demo

This is the demo application for the audio-ml library.

## Setup

Install dependencies:

```bash
yarn install
```

Or from the root directory:

```bash
cd demo && yarn install
```

## Development

Run the development server:

```bash
yarn dev
```

## Build

Build the demo for production:

```bash
yarn build
```

## Preview

Preview the production build:

```bash
yarn preview
```
